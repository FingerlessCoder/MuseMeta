在 Android Kotlin 中实现类似 iOS 的滚动数字选择器（Number Ring / Wheel Picker），最地道、最高效的方法是使用 RecyclerView 配合 SnapHelper。为了实现首尾相接的无限循环效果（59 后面接着 1），我们可以使用虚拟无限循环（Virtual Infinite Loop）的手法。

下面是完整的实现方案。

1. 布局文件
首先创建列表项的布局文件，用于显示单个数字。

res/layout/item_number_picker.xml

XML

<FrameLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="50dp">

        android:id="@+id/tvNumber"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_gravity="center"
        android:textSize="20sp"
        android:textColor="@android:color/black"
        android:textStyle="bold" />
</FrameLayout>
2. 适配器 (Adapter)
在适配器中，我们将 getItemCount() 返回一个极大的数字（例如 Int.MAX_VALUE），并通过取模运算 position % data.size 来让数字循环出现。

NumberPickerAdapter.kt

Kotlin
package com.example.timerpicker

import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.TextView
import androidx.recyclerview.widget.RecyclerView

class NumberPickerAdapter(private val items: List<Int>) :
    RecyclerView.Adapter<NumberPickerAdapter.NumberViewHolder>() {

    class NumberViewHolder(view: View) : RecyclerView.ViewHolder(view) {
        val tvNumber: TextView = view.findViewById(R.id.tvNumber)
    }

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): NumberViewHolder {
        val view = LayoutInflater.from(parent.context)
            .inflate(R.layout.item_number_picker, parent, false)
        return NumberViewHolder(view)
    }

    override fun onBindViewHolder(holder: NumberViewHolder, position: Int) {
        // Use modulo to simulate infinite loop
        val actualPosition = position % items.size
        holder.tvNumber.text = items[actualPosition].toString()
    }

    override fun getItemCount(): Int {
        // Return a very large number for pseudo-infinite scrolling
        return Int.MAX_VALUE
    }

    // Helper method to get the actual item from a specific position
    fun getItemAt(position: Int): Int {
        return items[position % items.size]
    }
}
3. Activity / Fragment 中的实现
在 Activity 中，我们需要做三件事：

使用 LinearSnapHelper 让滚动停止时自动对齐到正中间（类似 iOS 的卡位效果）。

初始化时，将 RecyclerView 定位到中间的某个位置，使用户向上或向下都有足够的滚动空间。

监听滚动状态，获取当前选中的数字。

MainActivity.kt

Kotlin
package com.example.timerpicker

import android.os.Bundle
import android.util.Log
import androidx.appcompat.app.AppCompatActivity
import androidx.recyclerview.widget.LinearLayoutManager
import androidx.recyclerview.widget.LinearSnapHelper
import androidx.recyclerview.widget.RecyclerView

class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        val recyclerView = findViewById<RecyclerView>(R.id.recyclerView)
        
        // 1. Create data from 1 to 59
        val numbers = (1..59).toList()
        val adapter = NumberPickerAdapter(numbers)
        
        val layoutManager = LinearLayoutManager(this, LinearLayoutManager.VERTICAL, false)
        recyclerView.layoutManager = layoutManager
        recyclerView.adapter = adapter

        // 2. Add SnapHelper for iOS-like snapping effect
        val snapHelper = LinearSnapHelper()
        snapHelper.attachToRecyclerView(recyclerView)

        // 3. Scroll to the middle of Int.MAX_VALUE to allow infinite scrolling up and down
        val middlePosition = (Int.MAX_VALUE / 2) - ((Int.MAX_VALUE / 2) % numbers.size)
        layoutManager.scrollToPosition(middlePosition)

        // 4. Listen for scroll changes to get the selected value
        recyclerView.addOnScrollListener(object : RecyclerView.OnScrollListener() {
            override fun onScrollStateChanged(recyclerView: RecyclerView, newState: Int) {
                super.onScrollStateChanged(recyclerView, newState)
                
                if (newState == RecyclerView.SCROLL_STATE_IDLE) {
                    val centerView = snapHelper.findSnapView(layoutManager)
                    centerView?.let {
                        val position = layoutManager.getPosition(it)
                        val selectedValue = adapter.getItemAt(position)
                        Log.d("TimerPicker", "Selected Number: $selectedValue")
                    }
                }
            }
        })
    }
}
💡 进阶优化建议
如果你想要更逼真的 iOS 3D 滚轮弧度效果（Wheel View），仅靠原生的 RecyclerView 会略显扁平。你可以考虑以下两种方案：

自定义 LayoutManager：修改 LinearLayoutManager，根据每个 Item 距离中心点的 Y 轴距离，动态计算其 rotationX（X轴旋转角度）和 scaleX / scaleY（缩放比例），从而形成中间大、两边小且向后倾斜的 3D 环形效果。

使用成熟的开源库：如果不想从零造轮子，可以直接使用专门封装好的库，例如 Barkoder/wheel-picker-angular 概念在 Android 端的实现，或者直接引入 com.github.IslandParadox:Android-WheelPicker 等开源组件，它们通常自带了阻尼感、遮罩层和 3D 弧度效果。
