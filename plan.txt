Here's the full diagnostic across all 7 areas after reading every key file:
1. Dynamic Island / MediaSession ❌ BROKEN
Root cause: Missing MediaNotification.Provider. MusicService creates MediaSession.Builder(this, player).build() but never provides a media notification. Android 12+ requires a notification to surface the media player in Quick Settings / Dynamic Island.
MusicService.onCreate():
  playerController.initialize()
  MediaSession.Builder(this, player).build()   ← no notification provider
  // Missing: setMediaNotificationProvider(...)
Koin is NOT the problem — service injects correctly via KoinComponent. The manifest has the right intent filter (MediaBrowserService) and foreground service type (mediaPlayback).
Fix: Add MediaNotification.Provider to MediaSessionService.
2. Album Art / Thumbnails ❌ BROKEN
MetadataParser.extractAlbumArt() successfully extracts album art as ByteArray during scan. But it's never saved to disk — ScanRepository.writeBatch() creates the AlbumEntity with only title, albumArtist, year:
val newAlbum = AlbumEntity(title = ..., albumArtist = ..., year = ...)  // artPath = null always
Then Coil tries to load file://${album.artPath} → always null → no art shown anywhere (AlbumList, AlbumDetail, Player).
Fix: Save albumArtBytes to internal cache dir during scan, set AlbumEntity.artPath.
3. Queue ⚠️ PARTIAL
Core queue works — MusicPlayerController.playFromQueue() sets up ExoPlayer with multiple MediaItems, skipToNext(), skipToPrevious() function via ExoPlayer's internal queue.
But the queue UI is invisible — PlayerViewModel.queueTracks defaults to emptyList() and is never populated from the controller's currentTrackPaths/currentTrackIds. Queue tab always shows "Queue is empty".
Fix: Expose currentTrackIds or queue tracks list from controller → ViewModel state.
4. Multi-Artist ✅ WORKS
- Parser: Splits on " feat. ", " ft. ", " featuring ", " & ", " / ", ", ", "; " — robust
- Storage: Independent ArtistEntity rows + TrackArtistEntity cross-ref table, duplicates deduplicated
- Display: 
- TrackListScreen / PlayerScreen: flat joinToString(", ") — not clickable to artist page
- AlbumDetailScreen: nice truncation (take(2) + "+N more"), artist names in primary color
- ArtistListScreen: all artists listed individually (including featured) ✅
- ArtistDetailScreen: shows tracks for a specific artist via cross-ref ✅
- Gap: Artist names in track lists should be clickable → navigate to artist detail
